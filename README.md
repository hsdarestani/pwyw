# PWYW — Play While You Wait

A multi-tenant, brand-native mini-game platform for real-world waiting spaces. Businesses create a branded game lounge, share a QR code, and see privacy-conscious usage analytics. See `docs/ARCHITECTURE.md` and `docs/DEPLOYMENT.md` for setup and operational controls.

**Status:** early pilot build. Game-based commercial ROI is not yet validated. Do not advertise performance promises.
